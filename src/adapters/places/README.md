# Places Adapter (`src/adapters/places`)

Contains the abstract `PlacesClient` interface wrapping Google Places API.

Provides structured queries for Pune exploration:

- Heritage sites (e.g. Shaniwar Wada, Aga Khan Palace, Sinhagad Fort)
- Food & dining (e.g. FC Road street food, traditional Maharashtrian bakeries)
- Accessible transit hubs and emergency facilities
