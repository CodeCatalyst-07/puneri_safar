# Reports Adapter (`src/adapters/reports`)

Contains the abstract `ReportsRepository` contract.

Handles real-time crowdsourced safety & hazard reporting:

- Potholes & dangerous road conditions
- Monsoon waterlogging chokepoints
- Broken streetlights & unlit stretches
- Firestore implementation targeted for later phase; offline test mock available in `tests/mocks/mockReportsRepository.ts`.
