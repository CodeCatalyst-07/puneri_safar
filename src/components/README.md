# Components Layer (`src/components`)

Accessible, reusable UI presentation components.

## Accessibility Guidelines (WCAG 2.1 AA)

- Must include semantic HTML landmarks (`<header>`, `<nav>`, `<main>`, `<footer>`).
- Form elements and interactive targets must have accessible labels and keyboard focus indicators.
- Must respect `prefers-reduced-motion`.
- All text and UI contrast ratios must satisfy at least 4.5:1 (normal text) and 3:1 (large text / graphics).
